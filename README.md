An interactive, high-performance personal developer portfolio built with **React, React Three Fiber, Tailwind CSS v4, and Vite**. Features an anti-template, left-aligned architectural design with a live 3D code-mesh universe, verified client testimonials, and interactive project showcases.

---

## 🚀 Key Features

- **Interactive 3D Universe:** Powered by `@react-three/fiber` and `@react-three/drei`, rendering floating code snippets, wireframe meshes, and depth fog.
- **Strict Anti-Template UI:** Bespoke asymmetrical grid layouts designed to avoid generic AI/Canva portfolio templates.
- **Client Testimonial Showcase:** Verified client reviews featuring Cosmo Radiance Aesthetic Center, Ashoka Vidya Mandir, and Sri Sampoornam.
- **Enterprise Case Studies:** Deep dives into proprietary Hospital Management Systems (HMS), autonomous AI agents, and 0ms latency Next.js architectures.
- **Smooth Cursor Interactions:** Custom emerald-accented cursor tracking and hover states.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, React Three Fiber, Three.js, Lucide Icons
- **Styling:** Tailwind CSS v4, Custom CSS Variables
- **Build Tool:** Vite
- **Deployment:** Vercel

---

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/NaniCherry131202/Charan-Portofilo.git

# Navigate into project directory
cd Charan-Portofilo

# Install dependencies
npm install

# Start development server
npm run dev
```
